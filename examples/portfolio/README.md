# Worked example: adammorad.com portfolio

A complete run of the skill on a one-page Next.js 16 + Tailwind v4 site, 2026-10-06.

- `DESIGN.md`: the law the owner approved (conflicts C1 to C7 decided, defaults on C2, C8, C9)
- `tokens-excerpt.css`: the CSS variables and `@theme` block it produced
- `ds/`: the wrapper components (the closed vocabulary)
- `recipes/`: five recipes with typechecked examples
- `experiment/`: the A/B brief, both arms' pages, arm B's plan, first draft, checker output and notes
- `screenshots/`: baseline and A/B renders
- `EXPERIMENT.md`: metrics, what the checker caught and missed, what A did better, limits, top 5 fixes

Paths inside these files (`src/components/ds`, `design-system/...`) refer to the original repo layout.
